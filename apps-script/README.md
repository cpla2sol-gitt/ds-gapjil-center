# 도입 문의 → Gmail 연결 방법

1. 센터용 구글 계정으로 https://script.google.com 접속 → **새 프로젝트**
2. `Code.gs` 내용을 통째로 붙여넣고, 맨 위 `TO`에 문의를 받을 메일 주소 입력 → 저장
3. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
4. **배포** → 권한 승인(메일 보내기 권한) → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사
5. 사이트의 `main.js` 맨 위 `FORM_ENDPOINT = ""` 따옴표 안에 그 주소 붙여넣기

- 무료 구글 계정은 하루 100통까지 보낼 수 있습니다.
- `Code.gs`를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.
